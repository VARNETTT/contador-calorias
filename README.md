CalorieTrack - corrección Coach IA en celular

- Respuestas dentro de área con desplazamiento vertical, sin tapar sugerencias ni campo de texto.
- Markdown básico **negrita** presentado sin mostrar asteriscos, mediante nodos DOM seguros.
- Botones de sugerencias en dos columnas en móvil.
- Mantiene unidades/porciones, agua, comidas y cinco círculos en fila.
